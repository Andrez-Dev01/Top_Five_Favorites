# Project: My Top Five Favorites

This repository contains my main project for my college web development course. It's a simple, dynamic website built from scratch to showcase my top five favorite things.

## 📚 About This Project

The goal of this project was to apply the fundamental concepts of front-end web development. It's a multi-page site that demonstrates proficiency in structuring content, styling it, and adding interactive elements.

This project was built for:
* **Course:** MCMPGR-267
* **College:** Modesto Junior College

## 💻 Technologies Used

This project was built using the core technologies of the modern web:

* **HTML5:** Used for the structure and content of all pages.
* **CSS3:** Used for all styling, including layout (like Flexbox or Grid), colors, and fonts.
* **JavaScript (ES6+):** Used to add dynamic behavior and interactivity to the site.

## ✨ Key Features

* A clean, multi-page layout.
* Responsive design that works on different screen sizes.
* Interactive elements handled by JavaScript.
* A showcase of my "top five" favorite topics, pages, or items.
